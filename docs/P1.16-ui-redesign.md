**Not:** LeetCode with different colors.

```text

├── Learn        → /learn (+ labs, topic notes)
```

| Surface | Mental model |
|---------|----------------|

## Design rules (enforce in UI.2+)

1. **Cards sparingly** — prefer whitespace + dividers
2. **Sky blue for interaction only** — CTAs, active nav, progress, links, focus (not decoration)
3. **95 / 4 / 1 ratio** — white & soft blue surfaces · blue-gray text/borders · sky-blue accent
4. **Progressive disclosure** — don't show every panel at once in workspaces
5. **No gamification clutter** — no acceptance rates, leaderboard chrome in v1
6. **Challenges ≠ Problems** — different layout language (UI.5)
7. **Verdict UX** — restrained, concept-first (backend already supports this)
